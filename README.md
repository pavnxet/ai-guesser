# 🔮 AI Guesser & Online Tools Suite

A web application powered by Qwen AI, designed for instant hosting on **GitHub Pages**.

## 🚀 Features

- **🧠 Mind Reader (Akinator Mode)**: AI asks 20 questions to guess what you're thinking of.
- **🕵️ Secret Keeper**: AI picks a secret item; ask Yes/No questions to crack it.
- **⚡ Speed Clues**: Enter 3 cryptic clues for instant AI deduction.
- **⚙️ Configurable API**: Pre-configured preview token with option to plug in your own Qwen API token.

## 🌐 Deploying to GitHub Pages

1. Push this repository to GitHub.
2. Go to **Repository Settings** -> **Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` branch and `/ (root)` directory, then click **Save**.
5. Your tools will be live at `https://<your-username>.github.io/<repo-name>/`.
